Full candidate tests terminate a real process during an uncommitted claim checkpoint, verify rollback, resume and compare every business-table digest. Deleting selected downstream stages and rebuilding must reproduce the same candidate while preserving unaffected ancestors. Failed native export must not publish a ready marker or committed failed-group checkpoint; complete resume compares every generated file hash with the primary export. The final gate binds actual candidate/source bytes, source and input files, all seed inspections, complete profile/control artifacts, source replay evidence, review selection and issue dispositions. A changed reviewed fact or assumption cannot inherit a passing gate.

## Review authority and limitations

The user delegated synthetic business/clinical/finance review to this agent. Recorded acceptance is scoped synthetic-data review, with no external licensed clinical, accountant or vendor endorsement. The bounded named-patient review and issue register explicitly disclose template-driven clinical scope, selected resource capture, security-grant cohort selection, fixed catchment across seeds and illustrative Axiom layouts. These limits prohibit broader interpretations; they do not waive structural rules, financial reconciliation, cutoff or volume limits.

Preexisting domain/source tests retain their historical scope after mapped code/input bytes are checked. The original clinical generator and financial planning/statistics oracle are explicitly version-bound to Git revision bfd89b22d54bac051a3daf4ea27adcae0c5475b2 because current code fixes a year-end patient-calendar trap and an out-of-period bed-projection dependency. Fresh boundary fixtures, unchanged unaffected-candidate golden digests and all three full seed experiments validate the fix; older tests are not claimed to test the changed generator. Other mapped files remain byte-identical. They are identified separately from freshly executed integrated tests; twelve source tests overlap the older totals. Changed financial facts receive fresh domain, consumer and source-file checks rather than inheriting an old data acceptance.

The boundary correction resolves an unpublished ordinary repeat-visit proposal in earlier free time when a late inpatient stay leaves no forward in-window slot. Linked urgent admission chains cannot move backward. If an earlier visit precedes the supporting chronic assertion, it receives a grounded episodic assessment instead of inheriting future knowledge. No seed, visit or failed case is discarded.

Monthly bed statistics read only effective events before the target period end. An incomplete later-period event stream cannot corrupt a complete closed month; unresolved gaps within the requested period still block the calculation. The producer and independent oracle both have positive/negative scope regressions.
